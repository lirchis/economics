# 我的经济学课堂

为正常工作、希望系统理解经济与市场的非经济学专业学习者设计。每周两节，每节专注一小时；第一轮共 **24 周、48 节课、48 小时课堂**。假期和复习可以顺延，不按日历催进度。无需必修课外阅读、提前学微积分或编程。

本仓库的中文讲义就是上课主教材。外部书籍、公开课和资料用于查证与选读，无需先买书才能开始。课程目标是解释机制、判断证据、理解取舍；金融部分学习企业与资产价格的基础，不以股票收益考核学习效果。

## 现在怎么开始

在这个项目中新开一个会话，输入：

> 开始第一课，请按项目里的教学说明带我上课，一次讲一个小段，等我回答后继续。

以后可以直接说：

> 开始下一课。今天有一小时。

> 继续上次没讲完的课。

> 今天到这里，请整理课堂记录和下次衔接。

老师会先读取课程进度、最近的课堂记录和待复习问题，再开始互动。正常完成一节课时，老师会主动生成课堂记录。**如果中途离开，说一句“保存本节进度”**，就能留下未完成的位置和讨论。新会话依靠仓库文档接续；若会话意外中断且尚未写入文件，需要在下次会话补充最后讨论到哪里。

## 一堂课是什么样

通常用 5 分钟回忆或诊断、15 分钟解释概念、15 分钟拆案例、15 分钟练习、10 分钟复述与收束。时间是教学预算，不是程序计时；有价值的疑问可以占用更多时间，剩余部分留到下次。

讲义含参考答案，默认折叠。上课时先自己尝试，老师根据回答补充讲解。预习、拓展阅读和课后练习都可选，必要学习尽量在这一小时里完成。

## 教材和课堂记录分别保存

- `lessons/L01.md` … `lessons/L48.md`：事先准备的教材，包含解释、案例、练习、参考答案和检验标准。发现教材问题时可修订。
- `sessions/YYYY-MM-DD-L01-01.md`：某次真实课堂的内容、你的问题与回答、补充解释、掌握证据、遗留问题及下次切入点。日期使用北京时间；同一课分几次上就保留几份记录。
- `course/progress.md`：唯一的课程进度总表，区分“讲义已备”和“实际完成”。
- `course/questions.md`、`course/review-queue.md`：跨会话的疑问和复习线索。
- `AGENTS.md`、`course/teaching-guide.md`：新会话接手教学时的工作约定。
