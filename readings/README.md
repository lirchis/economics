# 经典阅读与导读

本书单配合 [48 节课程](../course/syllabus.md)，目的是读懂作者提出的问题、推理和证据。书单共九项，不要求第一轮全部读完；其中《经济学原理》的微观、宏观两册算同一项。这里区分历史原典、教材、现代代表作与现实专题，不因为一本书有名就把其中所有判断当作结论。

## 先选哪些

**第一轮优先安排三项：曼昆《经济学原理》按课查读，《经济学规则》理解模型怎样使用，《置身事内》连接中国经济。** 同一时间只展开一本书；曼昆作为需要时翻阅的工具书，可以与另一本文字型读物并用。

如果你更想了解经济学家为什么会有不同观点，先加入 B02 的思想史选读；如果更关心证据怎么改变政策，先加入 B04；有投资兴趣则在金融课程后加入 B06。这三种兴趣不要求同时满足。

《国富论》《资本论》《通论》是有必要认识的重要原典，第一轮只读明确的小范围。先有概念和问题，再回到原文，会比从第一页硬读到最后更容易理解。其历史重要性、作者的理论主张、今天的证据支持程度要分别判断。

## 怎样开始一项阅读

每篇导读都提供一个小范围入口。一次可用约 20—30 分钟：先看导读中的问题，再读原书的一小节，最后记下一个疑问。不以读完多少页作为唯一目标，也不承诺三次阅读就能读完整本书。只有在你有额外时间时才增加课外阅读。

若没有课外时间，可以在原定课堂中拿 10—15 分钟对读一段，或用一整节课讨论一本书；当节课原计划没讲完，就在课程进度中如实保留。阅读并不自动计为完成对应课程。

当前最容易执行的一步：打开 [B01 导读](B01-principles.md)，读其中第一轮起步安排，再找原书有关机会成本与经济学分析方法的部分。暂时拿不到书，也可以照常开始 L01。

## 读书时固定问四个问题

1. 作者想解释什么现象？他主要回应谁、什么时代的问题？
2. 结论依赖哪些定义、假设和推理？这里的术语与课堂定义相同吗？
3. 作者给了什么证据？还有什么其他解释，什么观察会使结论改变？
4. 我能把它应用到哪个具体问题？应用时需要补充哪些制度和数据？

先准确重述作者，再评价。既不因作者有名跳过证据，也不因为旧书使用了旧术语就跳过它提出的问题。读历史原典尤其要区分“理解一种理论”与“接受它的一切结论”。

## 和老师一起读、怎样保存

在项目中新会话说：

> 带我读 B03《经济学规则》，今天先讨论模型为什么需要简化。

> 我在读 B05 里关于地方财政的一节，这段推理我不懂。

老师会读取对应导读与[阅读进度](progress.md)。如果需要逐句解释某个版本的原文，请说明版本和章节，提供你正在讨论的短段落，或一个可访问的合法来源；老师不会假装看到了你的纸书或未提供的页面。

讨论后，沿用项目的 `sessions/YYYY-MM-DD-QA-NN.md` 保存实际阅读对话，标注书号与版本，更新阅读进度和相关问题。简短笔记可参照[阅读笔记模板](../templates/reading-note.md)。没有实际阅读和回答，就不记“读完”或“掌握”；导读也不替代原书。
