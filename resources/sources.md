# 教材、数据与查证来源

本仓库原创中文讲义为主教材，外部资料均为选读和查证入口。可以不购买图书、不完成英文阅读，直接参加全部课堂。下面的入口在 2026-10-24 编写课程时经网页检索或读取核对；网站可变更，使用具体事实时仍需重新核对原文。

要选择书籍或获得读前提示，先看[经典阅读与导读](../readings/README.md)。每本书的独立导读列出已核验的书目信息、原文或出版社来源、选读范围与适用边界；本页继续作为课程的通用资料入口。

## 中国经济的官方资料

| 来源 | 适用课程 | 读取时要检查什么 |
| --- | --- | --- |
| [国家统计局指标解释](https://www.stats.gov.cn/sj/zbjs/) | L13—L15、L19、L25、L35 | 单位、人口范围、名义/实际、同比/环比、口径修订 |
| [国家统计局：什么是居民消费价格指数（CPI）](https://www.stats.gov.cn/zs/tjws/zytjzbqs/jmxxggzs/202409/t20240910_1956353.html) | L14、L25 | CPI 测量范围与个人消费篮子的差别；指数和涨幅的差别 |
| [中国人民银行](https://www.pbc.gov.cn/) | L17—L18、L39 | 从官网查找货币政策执行报告、统计数据、工具说明；区分发布时间与所属季度 |
| [财政部：中央政府预算](https://www.mof.gov.cn/zyyjsgkpt/zyzfyjs/zyys/) | L21、L37—L40 | 预算/执行/决算；中央本级/地方本级/全国；一般公共预算/政府性基金预算 |
| [财政部：2025 年中国财政政策执行情况报告](https://m.mof.gov.cn/czxw/202603/t20260317_3985436.htm) | L37、L40 的可选历史材料 | 发布于 2026-03-17，描述 2025 年；不能当作当前月份的数据 |
| [外汇局：2025 年四季度及全年国际收支平衡表](https://www.safe.gov.cn/safe/2026/0327/27297.html) | L22、L25 | 观察期、币种、储备资产与金融账户、贷借方符号；该版本发布于 2026-03-27，可能后续修订 |

官方统计是核对定义和原始发布的重要入口。发布机关对政策效果的解释仍应按研究设计和证据审读，不把“官方发布”自动等同于完整因果证明。

## 如何引用和更新

真实数据进入课堂记录时至少注明：来源链接、观察期、发布时间、指标名称、单位、地区或人群、必要的口径限制。由自己计算的结果写出计算式；教学假设必须明确标记，不能搭配官方来源让人误以为是真实统计。

本项目采用原创解释与案例，不存放外部教材全文，不提供未经授权的教材下载。资源链接表示阅读或核验入口，不表示外部机构为本课程背书。链接失效时先查官方新入口；找不到就注明未核验，并用教学假设继续讲清机制。
