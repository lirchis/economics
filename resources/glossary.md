# 概念速查

这里只提供回忆入口，定义、前提和练习以对应讲义为准。没有必要在上第一课前背下来。

## 选择、市场与组织

| 概念 | 一句话回忆 | 课程 |
| --- | --- | --- |
| 机会成本 | 一项选择所放弃的最佳可行替代的价值 | [L01](../lessons/L01.md) |
| 沉没成本 | 已发生、无法由当前选择收回的成本 | [L01](../lessons/L01.md) |
| 边际 | 再多或再少一点带来的变化 | [L01](../lessons/L01.md) |
| 模型 | 在明确假设下保留关键机制的简化描述 | [L02](../lessons/L02.md) |
| 均衡 | 在模型条件下，相关选择彼此相容的状态；不自动表示公平或最佳 | [L04](../lessons/L04.md) |
| 弹性 | 一个变量相对另一个变量的百分比变化敏感度 | [L05](../lessons/L05.md) |
| 税收归宿 | 税负最终由谁承担，不只看法律上谁缴税 | [L06](../lessons/L06.md) |
| 经济利润 | 收入扣除包括机会成本在内的经济成本 | [L07](../lessons/L07.md) |
| 市场势力 | 企业影响价格或交易条件的能力 | [L08](../lessons/L08.md) |
| 外部性 | 决策对交易之外的人造成、未充分反映在决策者成本收益中的影响 | [L09](../lessons/L09.md) |
| 公共品 | 具有非竞争性和非排他性特征的物品 | [L09](../lessons/L09.md) |
| 纳什均衡 | 给定其他人的策略，各方都没有单方面改策略的收益 | [L10](../lessons/L10.md) |
| 逆向选择 | 交易前的信息差异改变参与者构成 | [L11](../lessons/L11.md) |
| 道德风险 | 难以观察的行为在契约或保障下发生变化 | [L11](../lessons/L11.md) |

## 总体经济

| 概念 | 一句话回忆 | 课程 |
| --- | --- | --- |
| GDP | 一定时期经济体内生产活动创造的增加值总量，或相应最终产出的价值 | [L13](../lessons/L13.md) |
| 名义与实际 | 名义按当期货币或价格衡量，实际尝试剔除价格变化 | [L14](../lessons/L14.md) |
| 通胀 | 一般价格水平的持续上升；与单个商品涨价或股价上涨不同 | [L14](../lessons/L14.md) |
| 生产率 | 一定投入所能生产的产出；比较时需统一投入和产出口径 | [L15](../lessons/L15.md) |
| 宏观投资 | 资本形成等新增生产性投入，区别于个人买卖已有证券 | [L16](../lessons/L16.md) |
| 银行存款 | 储户的资产、银行的负债；不能与银行资本混同 | [L17](../lessons/L17.md) |
| 货币政策传导 | 政策工具通过利率、信用、预期等影响行为与总体经济的过程 | [L18](../lessons/L18.md) |
| 失业率 | 失业人数占劳动力人口的比例；具体统计定义需要核对 | [L19](../lessons/L19.md) |
| 财政赤字与债务 | 赤字通常是期间流量，债务是时点存量，两者并非完全机械对应 | [L21](../lessons/L21.md) |
| 汇率 | 一种货币相对另一种货币的价格，方向必须说明报价方式 | [L22](../lessons/L22.md) |
| 比较优势 | 相对于其他生产选择，机会成本更低 | [L23](../lessons/L23.md) |

## 证据、制度与金融

| 概念 | 一句话回忆 | 课程 |
| --- | --- | --- |
| 存量与流量 | 存量描述时点状态，流量描述一段时间内的发生量 | [L25](../lessons/L25.md) |
| 选择偏差 | 被观察或参与的对象并非可直接代表所研究的目标群体或对照 | [L27](../lessons/L27.md) |
| 反事实 | 同一对象在没有某项干预等另一状态下会出现的结果 | [L28](../lessons/L28.md) |
| 双重差分 | 比较处理组与对照组在前后时期的变化差异；因果解释依赖条件 | [L29](../lessons/L29.md) |
| 回归系数 | 特定模型中变量关系的估计，不自动具有因果含义 | [L30](../lessons/L30.md) |
| 基础概率 | 在观察新信号之前，某事件在相关群体中的发生概率 | [L31](../lessons/L31.md) |
| 行为偏差 | 实际判断与某种理性基准的系统性差异，需结合情境辨认 | [L33](../lessons/L33.md) |
| 制度 | 影响行为预期与激励的正式规则、非正式规范及执行安排 | [L34](../lessons/L34.md) |
| 社会流动性 | 个体或家庭经济位置随时间或跨代发生变化的程度 | [L35](../lessons/L35.md) |
| 转移支付 | 政府之间或政府向居民、企业等主体作出的、不以直接取得当期产品服务为交换的支付 | [L21](../lessons/L21.md)、[L37](../lessons/L37.md) |
| 利润与现金流 | 利润按会计确认原则计量，现金流记录实际现金流入流出 | [L41](../lessons/L41.md) |
| 现值 | 未来现金流按合适贴现率折算到当前的价值 | [L43](../lessons/L43.md) |
| 债券收益率 | 连接债券价格与约定未来现金流的回报率概念，区别于票面利率 | [L44](../lessons/L44.md) |
| 估值 | 在现金流、增长和风险等假设下判断价值的过程 | [L45](../lessons/L45.md) |
| 分散 | 降低对共同风险来源的集中暴露，不能消除全部风险 | [L46](../lessons/L46.md) |
| 市场预期 | 参与者对未来的判断及其在价格中的反映，并非可直接观察的单一共识 | [L47](../lessons/L47.md) |
